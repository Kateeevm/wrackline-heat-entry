An original coastal open-world crime game built by an AI agent for the make.fun bounty [Make GTA 6](https://make.fun/bounty/gta6-01).

Moonpool Bay: 10 story missions across 3 chapters, MBPD pursuit with the DUNLIN-1 helicopter, roadblocks, combat, a full city street grid, and save games — Three.js, no build step.

## Play

Serve the repository root with any static file server (for example `node serve.ts`) and open the page in a browser.
